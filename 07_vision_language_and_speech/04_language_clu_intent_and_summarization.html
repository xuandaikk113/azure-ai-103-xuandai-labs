Lab 07/04 · CLU project + Summarization

Tạo project CLU (intent/entity) + summarization trên Language Studio / New Foundry.

Language StudioCLUIntent/EntitySummarization

🧰 Language Studio tại language.cognitive.azure.com — các tính năng đã có đầy đủ trong New Foundry; Language Studio sẽ migrate sang Foundry 20/03/2027.
Mục tiêu: Vòng đời CLU: build schema → label → train → deploy; + thử summarization.

Chuẩn bị

  • Foundry resource + project (CLU cần Foundry resource).
  • Dữ liệu utterance mẫu.

Các bước trên Portal

  1. Tạo CLU project
    Language Studio/Foundry → Conversational Language Understanding → Create project.
  2. Build schema + label
    Định nghĩa intent + entity → gán nhãn các utterance mẫu.
  3. Train + deploy
    Train model → xem evaluation → Deploy.
  4. Test + Summarization
    Test prediction; thử Summarization (extractive/abstractive).
Nghiệm thu: Model CLU deploy được + trả top intent/entity.
Lưu ý thi: CLU thay LUIS; vòng đời schema→label→train→deploy→predict. 2 kiểu summarization. CLU retire 31/03/2029.

Tham khảo (trang có ảnh minh hoạ)

  • CLU quickstart — có ảnh
  • Language Studio → Foundry migration
