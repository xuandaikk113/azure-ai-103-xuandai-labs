Lab 07/05 · Translator (resource + document translation)

Tạo Translator resource; dịch text và dịch document qua blob, song song 05_translator_text_and_document_translation.py.

Azure PortalTranslatorDocument translation

ℹ️ Translator chủ yếu dùng qua API/SDK. Phần Portal: tạo Translator resource (portal.azure.com) để lấy key + region; Document Translation chạy qua blob.
Mục tiêu: Tạo Translator resource (key + region); dịch text và document (async qua blob).

Chuẩn bị

  • Subscription.
  • (Document) 2 blob container nguồn/đích + SAS.

Các bước trên Portal

  1. Tạo Translator resource
    portal.azure.com → Create a resource → Translator → lấy key + region.
  2. Dịch text
    Dùng SDK/REST với key + region (text translation).
  3. Document translation
    Blob nguồn (có file) + blob đích (rỗng) + SAS → chạy batch translation (async).
Nghiệm thu: Dịch được text; job document translation chạy xong, blob đích có file dịch.
Lưu ý thi: Translator cần region với key đa vùng. Document translation là async (long-running) qua blob + SAS.
