1. Tóm tắt

  • Image Analysis 4.0 (cũ: Computer Vision 3.x) = 1 call nhiều VisualFeatures: CAPTION/DENSE_CAPTIONS, TAGS, READ (OCR), OBJECTS, PEOPLE, SMART_CROPS. SDK azure-ai-vision-imageanalysis.
  • Language service (cũ: Text Analytics): NER (recognize_entities), PII + redaction (recognize_pii_entities → redacted_text), sentiment + opinion mining (analyze_sentiment(show_opinion_mining=True)).
  • CLU (Conversational Language Understanding, cũ: LUIS) = intent + entity; cần project + deployment. Summarization: extractive (chọn câu gốc) vs abstractive (viết lại) — đều long-running (begin_*).
  • Translator: text (nhanh, đồng bộ) vs document translation (async/long-running, đọc blob nguồn→đích, cần SAS).
  • Speech: STT (SpeechRecognizer), TTS (SpeechSynthesizer), SSML chỉnh rate/pitch/break/voice. Voice Live = realtime speech-to-speech, SDK async-only (websocket), gộp STT+LLM+TTS.
  • Image/Video generation (tạo ảnh/video) qua OpenAI images.generate/images.edit — khác hẳn phân tích ảnh; video generation là async job.

3. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
Image Analysis vs Image generationAnalysis = hiểu ảnh có sẵn (caption/tag/OCR/object) qua azure-ai-vision-imageanalysis. Generation = tạo ảnh từ text qua OpenAI images.generate. Đề "mô tả/đọc chữ trong ảnh" → Analysis; "vẽ ảnh từ prompt" → generation.
CLU vs LUISCLU là bản mới trong Language service; LUIS đã nghỉ hưu. Đề nhắc LUIS = đáp án cũ → chọn CLU.
Extractive vs Abstractive summaryExtractive = lấy nguyên câu quan trọng (begin_extract_summary). Abstractive = viết lại ngắn gọn bằng từ mới (begin_abstract_summary).
Translator text vs documentText = chuỗi ngắn, đồng bộ, nhiều target cùng lúc. Document = file (giữ layout/format), async qua blob + SAS. Đề "dịch hàng loạt file giữ định dạng" → document translation.
Content Safety vs Image/Text AnalysisContent Safety = kiểm duyệt an toàn (Hate/SelfHarm/Sexual/Violence, severity). Image/Text Analysis = trích thông tin (caption/entity). Đề "lọc nội dung độc hại" → Content Safety (lab 01).
Voice Live vs STT+TTS rờiVoice Live = 1 SDK realtime gộp STT+LLM+TTS (speech-to-speech), async-only. STT+TTS rời = tự ghép từng bước. Đề "hội thoại giọng nói realtime low-latency" → Voice Live.

4. Exam tips & bẫy

  • Đề nói "đọc chữ (OCR) trong ảnh/scan" → Image Analysis VisualFeatures.READ (OCR cũ đã thay).
  • Đề nói "che/ẩn thông tin cá nhân trong văn bản" → recognize_pii_entities → dùng redacted_text.
  • Đề nói "ý kiến về từng khía cạnh (món ăn/dịch vụ...)" → sentiment + opinion mining (show_opinion_mining=True).
  • Đề nói "hiểu ý định người dùng + trích entity trong hội thoại" → CLU (không LUIS).
  • Đề nói "tóm tắt giữ nguyên câu gốc" → extractive; "tóm tắt diễn đạt lại" → abstractive.
  • Đề nói "dịch nhiều tài liệu giữ định dạng" → Document Translation (async, blob+SAS); dịch chuỗi nhanh → Text Translation.
  • Đề nói "điều chỉnh tốc độ/cao độ/giọng đọc TTS" → SSML (rate/pitch/break/voice), chọn neural voice.
  • Đề nói "trợ lý giọng nói realtime" → Voice Live, nhớ code async (asyncio/websocket), không có bản sync.
  • Image Analysis 4.0: nhiều feature trong 1 call tiết kiệm request; SMART_CROPS trả vùng theo aspect ratio; OBJECTS/PEOPLE trả bounding box.
