Lab 07/01 · Vision Studio · Image Analysis (caption/tags/OCR)

Thử Caption/Tags/Read trên ảnh bằng Vision Studio, song song 01_vision_image_analysis_captions_tags_ocr.py.

Vision StudioImage Analysis 4.0Caption/Tags/Read

🧰 Vision Studio tại portal.vision.cognitive.azure.com (demo Image Analysis 4.0). Vision cũng là một Foundry Tool — chọn Vision resource trước.
Mục tiêu: Thử Caption, Dense captions, Tags, Read (OCR) trên ảnh.

Chuẩn bị

  • 1 Azure AI Vision / Foundry resource.
  • Ảnh mẫu.

Các bước trên Portal

  1. Mở Vision Studio
    portal.vision.cognitive.azure.com → chọn resource.
  2. Chọn tính năng
    Nhóm Image Analysis → 'Add captions', 'Extract common tags', 'Extract text (OCR)'.
  3. Thử ảnh
    Dùng ảnh mẫu hoặc upload → xem caption/tags/OCR + JSON.
Nghiệm thu: Caption + tags + text OCR hiển thị.
Lưu ý thi: Image Analysis 4.0: 1 call nhiều feature; Read thay OCR cũ. Caption giới hạn vài region (ngoài đó dùng 3.2).

Tham khảo (trang có ảnh minh hoạ)

  • Image Analysis 4.0 (Vision Studio) — có ảnh

Đối chiếu với code

Cùng việc này bằng code ở 01_vision_image_analysis_captions_tags_ocr.py. Portal = làm tay / trực quan; code = tự động hoá, CI-CD.

Tài liệu học — không phải nguồn chính thức. Giao diện Portal đổi thường xuyên; luôn đối chiếu link Microsoft Learn ở trên.
