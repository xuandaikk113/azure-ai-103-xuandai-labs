Review 03 · Build & Deploy Agents

Foundry Agent Service (create_version, get_openai_client), function tools vs built-in tools, MCP/A2A, Microsoft Agent Framework, hosted agent, Bing grounding vs web_search, OpenAPI & Azure Functions tool. Ôn nhanh + bẫy thi.

1. Tóm tắt

  • Foundry Agent Service = agent server-managed. Tạo qua project.agents.create_version(agent_name=..., definition=PromptAgentDefinition(model=..., instructions=..., tools=[...])); gọi qua project.get_openai_client().responses.create(...).
  • SDK 2026: gói riêng azure-ai-agents (create_agent) đã GỘP vào azure-ai-projects 2.x (create_version). AIProjectClient chỉ hỗ trợ Entra ID (keyless).
  • Custom function tool (FunctionTool): bạn tự chạy hàm Python → trả FunctionCallOutput trong vòng lặp tool-call. Built-in tools: Code Interpreter, File Search (cần vector store) chạy server-side.
  • Tool kết nối ngoài: MCPTool (chuẩn mở tool/data, có require_approval), A2A (agent gọi agent), OpenApiTool (gọi REST theo spec), AzureFunctionTool (serverless qua Storage Queue), BingGroundingTool / web_search (tri thức web).
  • Microsoft Agent Framework (code-first, async, Python ≥ 3.10/3.11): Agent(client=FoundryChatClient(...)) rồi await agent.run(...). Hợp nhất Semantic Kernel + AutoGen. Đổi provider = đổi client, cùng API.
  • Hosted agent nói "ngôn ngữ" Responses: expose endpoint /responses để deploy lên Foundry Hosted Agent.

2. Cú pháp cần nhớ

# Tạo & gọi agent (Foundry Agent Service):
from azure.ai.projects import AIProjectClient
from azure.ai.projects.models import PromptAgentDefinition, FunctionTool
with DefaultAzureCredential() as cred, \
     AIProjectClient(endpoint=ep, credential=cred) as project:
    agent = project.agents.create_version(
        agent_name="my-agent",
        definition=PromptAgentDefinition(model=MODEL, instructions="...", tools=[tool]))
    with project.get_openai_client(agent_name=agent.name) as oai:
        resp = oai.responses.create(input="...")      # gọi qua Responses
        print(resp.output_text)
    project.agents.delete_version(agent_name=agent.name,
                                  agent_version=agent.version, force=True)  # dọn

# Custom function tool — vòng lặp tool-call:
tool = FunctionTool(name="get_x", description="...", parameters={...}, strict=True)
for item in resp.output:
    if item.type == "function_call":
        out = my_python_func(**json.loads(item.arguments))
        tool_outputs.append(FunctionCallOutput(type="function_call_output",
                             call_id=item.call_id, output=json.dumps(out)))
resp = oai.responses.create(input=tool_outputs, previous_response_id=resp.id)

# Built-in tools: Code Interpreter + File Search (cần vector store):
vs = oai.vector_stores.create(name="store")
oai.vector_stores.file_batches.upload_and_poll(vector_store_id=vs.id, files=[...])
tools=[CodeInterpreterTool(), FileSearchTool(vector_store_ids=[vs.id])]

# Tools ngoài:
MCPTool(server_label="x", server_url=URL, require_approval="always")
OpenApiTool(openapi=OpenApiFunctionDefinition(name=..., spec=spec,
            auth=OpenApiAnonymousAuthDetails()))
AzureFunctionTool(azure_function=AzureFunctionDefinition(input_binding=..., output_binding=...))
BingGroundingTool(bing_grounding=BingGroundingSearchToolParameters(
    search_configurations=[BingGroundingSearchConfiguration(project_connection_id=...)]))
# web_search built-in (KHÔNG cần agent/connection): tools=[{"type":"web_search"}]

# Microsoft Agent Framework (code-first, async):
from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
agent = Agent(client=FoundryChatClient(project_endpoint=ep, model=MODEL,
              credential=DefaultAzureCredential()), instructions="...")
result = await agent.run("...")          # result.text

3. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
Custom function tool vs Azure Functions toolFunctionTool chạy in-process (code Python của bạn trong vòng lặp tool-call). AzureFunctionTool chạy serverless, bất đồng bộ qua Storage Queue (input/output binding). Đề "logic chạy serverless, scale độc lập" → Azure Functions tool.
Bing grounding vs web_search vs RAG (AI Search)Bing grounding = cần connection "Grounding with Bing" trong project (có phí, dữ liệu ra ngoài). web_search = built-in hosted tool, khai {"type":"web_search"} thẳng, KHÔNG cần agent/connection. RAG AI Search = tri thức nội bộ của bạn (chương 06). Đề "dữ liệu nội bộ công ty" → AI Search, không phải Bing.
Agent vs gọi model trực tiếpAgent = tài nguyên server-managed (có instructions + tools + version, quản lý vòng đời). Gọi model trực tiếp = chỉ một request. Đề "trợ lý bền, có tool, quản lý tập trung" → agent.
azure-ai-agents vs azure-ai-projectsGói riêng azure-ai-agents (create_agent) đã gộp vào azure-ai-projects 2.x (agents.create_version). Đề nhắc create_agent/gói riêng = dấu hiệu API cũ.
OpenAPI tool vs custom function toolOpenAPI tool = nạp sẵn spec, agent tự gọi REST, KHÔNG cần code wrapper; auth khai trong spec. Function tool = bạn viết hàm. Đề "đã có REST API + spec sẵn" → OpenAPI tool.
MCP vs A2AMCP = chuẩn mở để agent kết nối tool/data (một server tool). A2A = agent gọi agent khác như endpoint từ xa (phối hợp giữa hệ thống).
Agent Framework vs Semantic Kernel/AutoGenSemantic Kernel + AutoGen đã hợp nhất thành Microsoft Agent Framework (agent-framework-core + -foundry). Đề nhắc SK/AutoGen = ngữ cảnh cũ.

4. Exam tips & bẫy

  • Đề nói "tính toán/chạy code, vẽ biểu đồ" → Code Interpreter (built-in), không phải custom function.
  • Đề nói "tra cứu trong tài liệu của tôi" → File Search + vector store (cho vài file); nhiều/phức tạp → RAG AI Search (chương 06).
  • Đề nói "thông tin web mới, có citation" → Bing grounding (có connection) hoặc web_search; "dữ liệu nội bộ" → AI Search.
  • Đề nói "hành động nhạy cảm cần người duyệt" → require_approval (vòng lặp mcp_approval_request → McpApprovalResponse).
  • Đề nói "gọi REST API có sẵn, khỏi viết code" → OpenAPI tool; "logic serverless của bạn" → Azure Functions tool.
  • Đề nói "code-first, chạy nhiều provider, portable" → Microsoft Agent Framework; nhớ nó async + Python mới.
  • Đề nói "deploy agent thành endpoint HTTP" → Hosted Agent nói chuẩn /responses.
  • AIProjectClient KHÔNG nhận API key — chỉ DefaultAzureCredential; thiếu role data-plane → 401/403.
  • Luôn delete_version agent test để dọn tài nguyên.
