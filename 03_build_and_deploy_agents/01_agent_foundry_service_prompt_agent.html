Tạo & test prompt agent trong New Foundry Agents playground, song song 01_agent_foundry_service_prompt_agent.py.

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) (giữ nguyên project đang mở). Hướng dẫn này theo New Foundry — bật toggle đó ON trước khi làm.
Mục tiêu: Tạo 1 prompt agent (model + instructions) và test trong Agents playground.

Chuẩn bị

  • Foundry project + model deployed.

Các bước trên Portal

  1. Mở Agents
    New Foundry → Build → Agents → Create.
  2. Cấu hình agent
    Đặt name (KHÔNG đổi được sau) + description + chọn model + nhập instructions.
  3. Test playground
    Chat thử; chỉnh instructions tới khi ưng.
  4. Save version
    Save để tạo version bất biến (sửa sau = version mới).
Nghiệm thu: Agent trả lời theo instructions trong playground.
Lưu ý thi: Agent playground = prompt agent (model + instructions + tools). Save tạo immutable version.

Tham khảo (trang có ảnh minh hoạ)

  • Tạo agent trong Foundry portal — có ảnh

Đối chiếu với code

Cùng việc này bằng code ở 01_agent_foundry_service_prompt_agent.py. Portal = làm tay / trực quan; code = tự động hoá, CI-CD.
