Review 06 · RAG & Foundry IQ Grounding

Azure AI Search: vector + hybrid (BM25), semantic ranker, indexer/skillset enrichment, Foundry IQ knowledge base & agentic retrieval. Ôn nhanh + bẫy thi.

Implement RAGAzure AI SearchHybrid & SemanticFoundry IQ

1. Tóm tắt

  • Azure AI Search (cũ: Azure Cognitive Search) = engine retrieval cho RAG. Index chứa field text + field vector.
  • 3 kiểu truy vấn: keyword/BM25 (search_text) · vector (vector_queries, ngữ nghĩa) · hybrid = cả hai cùng lúc (hợp nhất bằng RRF).
  • Semantic Ranker = lớp L2 rerank trên top kết quả, thêm @search.reranker_score + captions & answers. Cần cấu hình semantic trên index.
  • Indexer + Skillset = pipeline ingest tự động: data source (blob) → indexer kéo dữ liệu → skillset AI enrichment (OCR/Split/Embedding) → index. Khác với tự push document bằng tay.
  • Foundry IQ (mới 2026) = knowledge base + agentic retrieval chạy trên AI Search: LLM tự lập kế hoạch truy vấn đa nguồn, permission-aware, trả lời có citation + activity log.
  • Reasoning effort của agentic retrieval đổi cost/latency; mức minimal = chỉ semantic (không gọi LLM planning).

2. Cú pháp cần nhớ

# HYBRID = search_text (BM25) + vector_queries (ngữ nghĩa) cùng 1 call:
from azure.search.documents import SearchClient
from azure.search.documents.models import VectorizedQuery
vector_query = VectorizedQuery(vector=embedding, k_nearest_neighbors=5, fields="contentVector")
results = search_client.search(
    search_text=query,                 # phần keyword (BM25)
    vector_queries=[vector_query])     # phần vector (ngữ nghĩa)

# SEMANTIC RANKER (L2 rerank + captions/answers):
from azure.search.documents.models import QueryType
results = search_client.search(
    search_text="Làm sao để đổi trả hàng?",
    query_type=QueryType.SEMANTIC,                 # bật semantic ranking
    semantic_configuration_name="my-semantic-config")
for doc in results:
    print(doc["@search.reranker_score"])           # điểm L2 (0-4), khác @search.score (BM25)

# FOUNDRY IQ — agentic retrieval từ 1 knowledge base:
client = KnowledgeBaseRetrievalClient(endpoint, knowledge_base_name="kb1",
                                      credential=DefaultAzureCredential())
result = client.retrieve(retrieval_request=request)   # 'retrieval_reasoning_effort' cao -> kỹ hơn, tốn/chậm hơn

# INDEXER + SKILLSET (control plane, azure.search.documents.indexes):
#   SearchIndexerClient -> SearchIndexerSkillset(skills=[OcrSkill, SplitSkill, AzureOpenAIEmbeddingSkill])
#   -> SearchIndexer(data_source_name, skillset_name, target_index_name) -> run_indexer(...)

3. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
Vector vs Hybrid vs Semantic RankerVector = tìm theo embedding (ngữ nghĩa). Hybrid = vector + BM25 keyword gộp (RRF). Semantic Ranker = rerank L2 sau truy vấn + captions/answers — là bước thêm, không thay hybrid.
Indexer/Skillset vs manual pushIndexer = tự pull từ data source theo lịch + enrich bằng skillset. Manual push = app tự đẩy document qua upload_documents (tự lo chunking/embedding).
Foundry IQ agentic retrieval vs plain queryPlain query = 1 câu → 1 lần search. Agentic retrieval = LLM tách câu hỏi thành nhiều subquery, chạy nhiều lượt, tổng hợp có citation. Minimal effort bỏ phần LLM (chỉ semantic).
AI Search RAG vs Bing groundingAI Search = tri thức nội bộ bạn tự index (riêng tư). Grounding with Bing = tri thức web công khai, mới (lab 03/07). Đề "dữ liệu nội bộ công ty" → AI Search; "tin tức/web mới nhất" → Bing.
Semantic Ranker vs Semantic/vector searchSemantic Ranker (L2 rerank, tốn thêm tier) ≠ "semantic" nghĩa chung của vector search. Reranker_score thang 0-4; score BM25 không giới hạn.

4. Exam tips & bẫy

  • Đề nói "kết hợp từ khoá chính xác + hiểu ngữ nghĩa" → Hybrid search (search_text + vector_queries).
  • Đề nói "cải thiện thứ hạng kết quả, lấy câu trả lời trực tiếp/captions" → bật Semantic Ranker (query_type=SEMANTIC + semantic config).
  • Đề nói "tự động ingest PDF scan từ blob, OCR rồi chunk + embed" → Indexer + Skillset (OCR skill, Split skill, Embedding skill), không viết tay.
  • Đề nói "agent tự quyết định truy vấn nhiều nguồn, permission-aware, có citation" → Foundry IQ knowledge base + agentic retrieval.
  • Đề nói "giảm chi phí/latency retrieval, không cần LLM planning" → reasoning effort minimal (chỉ semantic).
  • Đề nói "dữ liệu nội bộ riêng tư" → AI Search; "thông tin web mới" → Bing grounding. Đừng lẫn.
  • Vector search cần index có field vector + tạo embedding trước (cùng model embedding lúc index & lúc query).
  • Least privilege để agent chỉ đọc index RAG → role Search Index Data Reader (không phải Search Service Contributor).
  • Preview Foundry IQ: tối đa 10 knowledge source/knowledge base.
