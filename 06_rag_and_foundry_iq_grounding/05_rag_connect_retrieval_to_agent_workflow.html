Lab 06/05 · Gắn retrieval vào Agent (grounding)

Gắn knowledge base / Azure AI Search tool vào agent trên New Foundry, song song 05_rag_connect_retrieval_to_agent_workflow.py.

Foundry Portal (new)AgentsKnowledge base / AI Search tool

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) (giữ nguyên project đang mở). Hướng dẫn này theo New Foundry — bật toggle đó ON trước khi làm.
Mục tiêu: Cho agent tự truy vấn index / knowledge base khi cần, trả lời có citation (RAG agentic).

Chuẩn bị

  • 1 agent (03/01).
  • 1 knowledge base (06/04) hoặc index + connection AI Search trong project.

Các bước trên Portal

  1. Mở Agents
    New Foundry → Build → tab Agents → tạo/chọn agent.
  2. Thêm tool tri thức
    Trong agent → Add tool → chọn Knowledge base (Foundry IQ) hoặc Azure AI Search (trỏ connection + index).
  3. Yêu cầu trích dẫn
    Trong Instructions, yêu cầu agent luôn kèm citation nguồn.
  4. Thử
    Playground của agent → hỏi câu cần tra tài liệu → xem trả lời + nguồn.
Nghiệm thu: Agent trả lời dựa trên tài liệu và hiển thị citation.
Lưu ý thi: RAG agentic: agent tự quyết định truy vấn. KB expose qua MCP endpoint; agent nối qua MCP tool (label 'knowledge-base') hoặc Azure AI Search tool.

Tham khảo (trang có ảnh minh hoạ)
