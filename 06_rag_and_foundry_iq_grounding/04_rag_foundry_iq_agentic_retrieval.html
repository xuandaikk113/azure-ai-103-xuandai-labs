2 cách tạo: (A) New Foundry → Build → Knowledge, hoặc (B) Azure Portal → search service → Agentic retrieval. Tính năng agentic retrieval ở portal hiện còn preview.
Mục tiêu: Tạo 1 knowledge base (Foundry IQ) và chạy agentic retrieval — tự lập kế hoạch truy vấn, trả lời có citation.

Chuẩn bị

  • Search service: bật RBAC + system-assigned managed identity; gán cho user: Search Service Contributor + Index Data Contributor/Reader.
  • Foundry resource: gán Cognitive Services User cho managed identity của search service.

Luồng tổng quan

flowchart LR KS[Knowledge source] --> KB[Knowledge base] KB --> AR[Agentic retrieval] AR --> ANS[Trả lời + citation]

Các bước trên Portal

  1. (Cách A · Foundry) Knowledge
    New Foundry → Build (top menu) → tab Knowledge → tạo knowledge base, thêm từng knowledge source, cấu hình retrieval behavior.
  2. (Cách B · Azure) Knowledge source
    search service → Agentic retrieval → Knowledge sources → vd Azure blob (Indexed), kind = Microsoft Foundry → chọn subscription/project/embedding.
  3. (Cách B) Knowledge base
    Agentic retrieval → Knowledge bases → kind Microsoft Foundry → chọn LLM deployment → attach knowledge source → Create.
  4. Thử
    Dùng Search Explorer / API retrieve để test; xem index sinh ra + activity log.
Nghiệm thu: Knowledge base trả câu trả lời có trích dẫn; activity log cho thấy các bước truy vấn.
Lưu ý thi: Foundry IQ chạy trên Azure AI Search; agentic retrieval tự lập kế hoạch đa nguồn. Reasoning effort đổi cost/latency; minimal = chỉ semantic (không LLM). Preview: tối đa 10 knowledge source/KB.
