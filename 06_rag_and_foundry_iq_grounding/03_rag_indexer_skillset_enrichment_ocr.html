Lab 06/03 · Indexer + Skillset (OCR, chunking)

Dựng pipeline ingest (data source → skillset → indexer) trên Azure AI Search.

Azure AI SearchIndexerSkillsetOCR

ℹ️ Đây là Azure Portal (portal.azure.com), KHÔNG phải Foundry portal — không có nút toggle "New Foundry". Làm theo điều hướng Azure Portal bên dưới.
Mục tiêu: Tự động ingest từ Blob: OCR ảnh/scan + chia chunk + (tuỳ) vector, qua indexer + skillset.

Chuẩn bị

  • Search service + Blob container 'documents' có tài liệu.

Các bước trên Portal

  1. Chạy wizard
    search service → Import data (new) → chọn Blob làm data source.
  2. Bật enrichment
    Wizard tự tạo skillset (chunk + embedding). Cần OCR ảnh/PDF scan → dùng 'Import data' cổ điển + OCR skill + Split skill.
  3. Tạo indexer
    Wizard tạo indexer nối data source → skillset → index và chạy theo lịch.
  4. Kiểm tra
    Tab Indexers xem trạng thái execution; Search Explorer kiểm tra dữ liệu đã vào index.
Nghiệm thu: Indexer chạy Success; index có dữ liệu đã enrich.
Lưu ý thi: Indexer = tự động kéo dữ liệu; Skillset = AI enrichment (OCR / split / embedding). OCR dùng cho scan/ảnh.

Tham khảo (trang có ảnh minh hoạ)

  • Import data wizard (skillset/OCR) — có ảnh
  • Import and vectorize data wizard — có ảnh
