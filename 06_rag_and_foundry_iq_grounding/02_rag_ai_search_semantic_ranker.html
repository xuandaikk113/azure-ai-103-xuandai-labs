Lab 06/02 · Semantic Ranker (rerank L2 + captions)

Bật semantic ranker + semantic configuration trên Azure AI Search, song song 02_rag_ai_search_semantic_ranker.py.

Azure AI SearchSemantic rankerSemantic configuration

ℹ️ Đây là Azure Portal (portal.azure.com), KHÔNG phải Foundry portal — không có nút toggle "New Foundry". Làm theo điều hướng Azure Portal bên dưới.
Mục tiêu: Bật semantic ranker và tạo semantic configuration để rerank (L2) + lấy captions/answers.

Chuẩn bị

  • Search service Basic+ và Semantic ranker đã enable trên service.
  • Đã có 1 index.

Các bước trên Portal

  1. Enable semantic ranker
    search service → Settings → Semantic ranker → chọn gói (Free/Standard).
  2. Tạo semantic configuration
    Khi tạo index qua 'Import data (new)' bật semantic ranking, HOẶC sửa index thêm semanticConfiguration (chọn title/content/keywords fields).
  3. Thử trong Search Explorer
    Search Explorer → Query type = Semantic → nhập query → xem reranker score + captions.
Nghiệm thu: Kết quả có @search.reranker_score và captions.
Lưu ý thi: Semantic ranker là rerank L2 (sau BM25/vector). Cần enable trên service + semantic configuration trên index.

Tham khảo (trang có ảnh minh hoạ)

  • Import and vectorize data wizard — có ảnh
