Lab 01/04 · Project & Connected resources

Xem project + quản lý connection (AI Search/Storage/Key Vault) trên New Foundry Portal.

Foundry Portal (new)ConnectionsManage

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) (giữ nguyên project đang mở). Hướng dẫn này theo New Foundry — bật toggle đó ON trước khi làm.
Mục tiêu: Xem cấu hình project và thêm/kiểm tra connection tới các tài nguyên (AI Search, Storage, Key Vault, model provider).

Chuẩn bị

  • Foundry project + quyền Azure AI Developer.

Các bước trên Portal

  1. Mở Project details
    Bật New Foundry → Manage (góc trên phải) → Project details (pane trái).
  2. Xem Connected resources
    Tab Connected resources → danh sách các connection hiện có + loại.
  3. Thêm connection
    Add connection → chọn loại (vd Azure AI Search) → nhập resource + cách auth → Add.
  4. Xem toàn bộ (Admin)
    Operate → Admin để xem all-resources, user management, connected resources cấp cao hơn.
Nghiệm thu: Connection mới hiện trong tab Connected resources và dùng được từ code (project.connections.list()).
Lưu ý thi: Project là trung tâm; connection ưu tiên Entra ID. Management center (Connected resources) là đường dẫn CLASSIC.

Tham khảo (trang có ảnh minh hoạ)

  • Add a connection (new portal)
  • Migrate from classic — vị trí nút toggle
