Lab 01/02 · Deploy model (Standard / Global / PTU)

Hướng dẫn trực quan trên Microsoft Foundry Portal — giao diện MỚI (New Foundry), song song với file code 02_deploy_openai_model_standard_and_ptu.py.

Foundry Portal (new)Deploy model Standard · Global · PTU~5 phút

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) — nó giữ nguyên project bạn đang mở. Hướng dẫn này theo New Foundry, nên hãy bật toggle đó ON trước khi làm. (Vài tính năng cũ như network isolation đầy đủ, Prompt Flow còn nằm ở classic.)
Mục tiêu: tạo 1 deployment cho model (vd gpt-4o / gpt-5.1-mini), rồi lấy endpoint + tên deployment để code gọi được.

Chuẩn bị

  • Có 1 Foundry project (chưa có: ai.azure.com → Create project).
  • Quyền Azure AI Developer (hoặc Owner/Contributor) trên resource.
  • Còn quota cho model ở region muốn deploy.

Các bước trên Portal (New Foundry)

  1. Đăng nhập & bật New Foundry
    Vào ai.azure.com → đảm bảo công tắc New Foundry ở banner trên cùng đang ON → chọn project.
  2. Mở danh mục model
    Góc trên phải chọn Discover → pane trái chọn Models.
  3. Chọn model
    Tìm gpt-4o → mở model card xem chi tiết → bấm Deploy (hoặc Use this model).
  4. Xác nhận deployment type — portal tự chọn type theo model + môi trường. Có thể đổi:
    Deployment typeKhi nào dùng
    Standard (khuyến nghị trong Foundry resource)token-based, theo region
    Global Standardtoken-based, dung lượng toàn cầu
    Provisioned (PTU)throughput cố định, trả theo giờ — tải lớn/ổn định
  5. Đặt tên + capacity → Deploy
    Deployment name: gpt-4o · Capacity: vd 10 → Deploy.
  6. Lấy thông tin cho code
    Mở deployment → copy Target URI / endpoint và Deployment name vào .env.
Nghiệm thu: deployment trạng thái Succeeded, và chat thử được ở Playground → chọn deployment → gõ câu hỏi.

Ví dụ .env sau khi deploy

AZURE_OPENAI_ENDPOINT=https://my-foundry.openai.azure.com/
AZURE_OPENAI_CHAT_DEPLOYMENT=gpt-4o        # = Deployment name (KHÔNG phải tên model gốc)
Lưu ý thi: model= trong code là tên deployment. PTU tính tiền theo giờ kể cả khi không gọi — xoá deployment test để tránh phí.

Tham khảo (trang có ảnh minh hoạ)

  • Migrate from Foundry (classic) — vị trí nút toggle.
