Review 01 · Foundry Setup & Deployments

Auth (key vs keyless), tạo deployment & các SKU/Deployment Type, content safety, fine-tune. Ôn nhanh + bẫy thi.

Plan & manageDeployments & SKUContent SafetyFine-tune

1. Tóm tắt

  • Auth: keyless (DefaultAzureCredential + token provider) là best practice; API key chỉ để thử nhanh.
  • Scope token: Azure OpenAI /v1 & Foundry Models → https://ai.azure.com/.default; AzureOpenAI classic (azure_endpoint + api_version) → https://cognitiveservices.azure.com/.default.
  • Deployment: chọn model + SKU (loại hạ tầng/billing) + capacity. OpenAI qua Azure OpenAI; non-OpenAI qua Serverless (MaaS).
  • Content Safety: 4 category (Hate/SelfHarm/Sexual/Violence), severity 0/2/4/6; mặc định chặn Medium+High. RAI policy gắn vào deployment.
  • Fine-tune: tùy biến model bằng JSONL; khác RAG, khác prompt. Có chi phí hosting riêng.

3. Cú pháp cần nhớ

# Keyless cho /v1 (OpenAI SDK):
from azure.identity import DefaultAzureCredential, get_bearer_token_provider
token_provider = get_bearer_token_provider(DefaultAzureCredential(), "https://ai.azure.com/.default")
client = OpenAI(base_url=".../openai/v1/", api_key=token_provider)

# Tạo deployment (control plane) với SKU + capacity:

4. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
Azure OpenAI endpoint vs Foundry Models endpointCùng OpenAI /v1 nhưng: Azure OpenAI = model OpenAI; Foundry Models = catalog non-OpenAI (MaaS). Scope token giống nhau (ai.azure.com).
Content Safety (SDK riêng) vs Content Filter / RAI policyContent Safety = API phân tích text/ảnh độc lập. RAI policy = bộ lọc gắn vào deployment Azure OpenAI (chặn tự động). TODO: override RAI qua ARM API.
Fine-tune vs RAG vs Prompt engineeringFine-tune: đổi trọng số (cần JSONL, tốn hosting). RAG: thêm tri thức lúc chạy. Prompt: chỉ đổi chỉ dẫn. Đề hỏi "thêm kiến thức mới thường xuyên" → RAG, không fine-tune.
PTU vs StandardPTU = capacity reserved, latency ổn định. Standard = per-token, co giãn theo quota.

5. Exam tips & bẫy

  • Đề nói "latency ổn định, throughput đảm bảo, lưu lượng lớn" → Provisioned Managed (PTU).
  • Đề nói "xử lý hàng loạt offline, tiết kiệm chi phí" → Batch.
  • Đề nói "data phải ở trong EU/US" → Data Zone Standard/Provisioned.
  • Đề nói "deploy model Llama/Mistral" → Serverless MaaS, gọi qua OpenAI /v1.
  • Đề nói "không hard-code secret" → keyless DefaultAzureCredential + role data-plane.
  • Content Safety: nội dung severity 0 (safe) không bao giờ bị chặn, chỉ được annotate. Prompt Shields chống jailbreak (khác 4 category).
