Lab 01/06 · Fine-tuning (model customization)

Tạo fine-tuning job trên New Foundry Portal, song song 06_finetune_model_customization.py.

Foundry Portal (new)Fine-tuningJSONL

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) (giữ nguyên project đang mở). Hướng dẫn này theo New Foundry — bật toggle đó ON trước khi làm.
Mục tiêu: Fine-tune 1 model cho domain riêng: upload dữ liệu JSONL → chạy job → deploy model đã customize.

Chuẩn bị

  • Foundry project.
  • File train/validation định dạng JSONL (mỗi dòng 1 ví dụ hội thoại).

Các bước trên Portal

  1. Mở Fine-tuning
    Bật New Foundry → pane trái tìm Fine-tuning (trải nghiệm mới từ Ignite 2025).
  2. Tạo job
    Create / + Fine-tune → chọn base model hỗ trợ fine-tune (vd gpt-4o-mini, Llama, Mistral).
  3. Upload dữ liệu
    Tải file training (+ validation) JSONL → chọn kỹ thuật (SFT / DPO / RFT nếu hỗ trợ) → Submit.
  4. Theo dõi & deploy
    Chờ job Succeeded → Deploy model fine-tuned → lấy tên deployment để gọi.
Nghiệm thu: Job trạng thái Succeeded; model fine-tuned deploy được và chat thử trong Playground.
Lưu ý thi: Fine-tune ≠ RAG ≠ prompt. Cần JSONL. Model fine-tuned có chi phí HOSTING riêng theo giờ. Một số AI-service fine-tune còn ở classic (toggle OFF).
