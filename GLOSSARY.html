Glossary · AI-103

Thuật ngữ trong bộ lab & hệ sinh thái Microsoft Foundry / Azure AI. Gõ để lọc; nhấn thuật ngữ in đậm để nhớ.

Nền tảng Foundry

Microsoft Foundry
Nền tảng xây dựng, deploy, vận hành app và agent AI trên Azure.
↩ tiền nhiệm: Azure AI Foundry
New Foundry toggle
Công tắc ở banner trên cùng portal, chuyển giữa giao diện New và Classic, giữ nguyên project đang mở.
Foundry (classic)
Giao diện Foundry cũ; vẫn cần cho vài tính năng chưa có ở new (network isolation đầy đủ, hub-based project, một số fine-tune).
Foundry project
Đơn vị trung tâm chứa agent, deployment, connection và dữ liệu của 1 giải pháp.
Model catalog / Discover → Models
Nơi duyệt và deploy model (ở new portal: Discover → Models).
Deployment
Một bản triển khai model, có TÊN riêng; code gọi model qua tên deployment này.
Standard / Global Standard / PTU (Provisioned Throughput Unit)
Các kiểu deployment: token-based theo region / token-based toàn cầu / Provisioned (throughput cố định, trả theo giờ).
Playground
Nơi thử model/agent trực quan trên portal, không cần viết code; có View code.
Connection / Connected resources
Liên kết project tới tài nguyên ngoài (AI Search, Storage, Key Vault, Bing, model provider).
Quota / Rate limit
Giới hạn dung lượng (TPM/PTU) và tốc độ gọi model theo region.

Xác thực & Bảo mật

Microsoft Entra ID
Dịch vụ quản lý danh tính (user, group, app, managed identity).
↩ tiền nhiệm: Azure Active Directory (Azure AD)
DefaultAzureCredential
Credential keyless tự thử lần lượt nhiều nguồn: Environment → ManagedIdentity → AzureCli…
Service principal
Danh tính cho phần mềm (app registration) trong tenant; BẠN tự giữ secret/cert, dùng được MỌI NƠI (local/CI-CD/cloud khác). Managed identity là 1 loại SP đặc biệt.
Managed identity
SP ĐẶC BIỆT do Azure tự tạo & quản lý credential cho 1 tài nguyên Azure (VM/App Service/Function) → KHÔNG secret, chỉ dùng khi workload chạy TRÊN Azure. Khác SP thường: Azure giữ mật khẩu hộ. System-assigned (gắn 1 resource) vs user-assigned (dùng chung).
Keyless vs API key
Keyless = token Entra ID (khuyến nghị); API key = chuỗi bí mật tĩnh (dễ lộ).
token provider (get_bearer_token_provider)
Hàm cấp & tự làm mới access token; truyền vào api_key của OpenAI /v1 client.
Token scope
Phạm vi quyền của token (vd https://ai.azure.com/.default cho Azure OpenAI v1).
RBAC (Role-Based Access Control)
Phân quyền = principal + role + scope; quyền thừa kế xuống các cấp dưới.
Principal (security principal)
Danh tính ĐƯỢC gán quyền: user, group, service principal hoặc managed identity. Trong code, `principal_type` chỉ rõ loại.
Role assignment
Phép gán cụ thể = principal + role definition + scope. Xoá assignment để thu hồi quyền.
Role definition
Bộ quyền của một role (actions/dataActions); built-in (Azure định sẵn) hoặc custom (tự định nghĩa).
Built-in vs Custom role
Built-in: role Azure định sẵn (vd Foundry User, Cognitive Services OpenAI User); custom: tạo khi built-in không vừa.
RBAC scope (4 cấp)
Phạm vi gán quyền: Management group → Subscription → Resource group → Resource; thừa kế xuống. KHÁC Token scope (OAuth).
Control plane vs Data plane
Control plane (actions): quản lý resource qua ARM. Data plane (dataActions): thao tác dữ liệu bên trong (gọi model, đọc blob) — keyless cần role data-plane.
Least privilege
Nguyên tắc: cấp role hẹp nhất, scope nhỏ nhất đủ dùng.
Private Endpoint / VNet (Virtual Network) / NSG (Network Security Group)
Mạng riêng: IP riêng cho dịch vụ PaaS, tắt public access; NSG là firewall theo IP/port.
Key Vault
Dịch vụ lưu secret/key/cert tập trung; app lấy qua managed identity.

Generative AI

LLM / SLM (Large / Small Language Model)
Large / Small Language Model — mô hình ngôn ngữ lớn/nhỏ.
Multimodal model
Model nhận nhiều phương thức đầu vào/ra (text, ảnh, audio).
Embedding
Vector số biểu diễn ngữ nghĩa của text, dùng cho tìm kiếm/RAG.
Token
Đơn vị văn bản model xử lý; dùng để tính chi phí và giới hạn.
Temperature / top_p
Tham số điều chỉnh độ ngẫu nhiên/đa dạng của đầu ra (0 = ổn định).
System message
Chỉ dẫn định hình vai trò/giọng điệu cho model.
Few-shot
Cho ví dụ mẫu trong prompt để model bắt chước định dạng.
Grounding
Chèn dữ liệu thật vào ngữ cảnh để giảm 'bịa'.
Hallucination / fabrication
Model bịa thông tin sai; grounding/RAG giúp giảm.
Structured output / JSON Schema (strict)
Ép model trả JSON đúng schema (strict + additionalProperties=false).
Streaming
Nhận đầu ra theo từng mảnh (delta) theo thời gian thực.
Context window
Giới hạn số token model nhớ được trong 1 lần gọi.
Prompt engineering
Kỹ thuật viết prompt + chỉnh tham số để tối ưu đầu ra.

SDK & API

openai SDK
Thư viện Python gọi model OpenAI/Azure OpenAI/Foundry Models.
AzureOpenAI (classic)
Lớp client dùng azure_endpoint + api_version; vẫn chạy nhưng không còn ưu tiên.
↩ tiền nhiệm: openai<1.0 (openai.ChatCompletion)
OpenAI /v1 API
Cách KHUYẾN NGHỊ: OpenAI client + base_url .../openai/v1/, KHÔNG cần api_version, auto-refresh token.
Responses API
API thế hệ mới cho agentic/multi-turn; nối lượt qua previous_response_id.
↩ tiền nhiệm: Chat Completions + Assistants API
previous_response_id
Nối hội thoại liên tục mà không gửi lại toàn bộ lịch sử (state nhẹ phía server).
Conversations API
Quản lý hội thoại server-managed (create/items/delete).
↩ tiền nhiệm: Threads/Runs (Assistants)
azure-ai-projects / AIProjectClient
SDK vào Foundry project; chứa agents, connections, get_openai_client.
↩ tiền nhiệm: azure-ai-agents (đã gộp)
agents.create_version / PromptAgentDefinition
Cách tạo agent trong azure-ai-projects 2.x.
↩ tiền nhiệm: create_agent
azure-ai-inference
SDK suy luận Foundry Models — ĐÃ DEPRECATED, retire 2026-08-26 → dùng OpenAI /v1.
Foundry Models / MaaS (Serverless API)
Catalog model (OpenAI & non-OpenAI) qua endpoint OpenAI /v1 thống nhất; MaaS = Model-as-a-Service.

Agents

Prompt agent
Agent định nghĩa bằng model + instructions (+ tools/knowledge); tạo trong playground.
Hosted agent
Agent đóng gói thành HTTP endpoint chuẩn Responses để triển khai.
Tool (Configured vs Catalog)
Khả năng gắn cho agent: Configured = built-in (Code Interpreter, File Search); Catalog = thêm (Bing, AI Search, MCP…).
Function tool
Hàm tự viết gắn cho agent qua JSON schema; agent gọi khi cần.
Code Interpreter
Built-in tool chạy code (tính toán/biểu đồ).
File Search
Built-in tool tra cứu file đã index (cần vector store).
Vector store
Kho vector cho File Search; chứa file đã nhúng.
MCP (Model Context Protocol)
Model Context Protocol — chuẩn mở kết nối tool/data từ server ngoài vào agent.
A2A (Agent-to-Agent)
Agent-to-Agent — một agent gọi agent khác như endpoint từ xa.
OpenAPI tool
Gắn API ngoài bằng OpenAPI spec; agent tự gọi REST, không cần code wrapper.
Azure Functions tool
Agent kích hoạt function serverless qua storage queue (async).
Grounding with Bing
Tool web search cho dữ liệu mới + citation; có chi phí & điều khoản riêng.
require_approval
Cơ chế buộc phê duyệt thủ công trước khi agent chạy tool nhạy cảm.
Thread / Conversation / Run
Thread/Conversation giữ lịch sử phía server; Run là 1 lần xử lý.
Microsoft Agent Framework
SDK code-first dựng agent (class Agent, FoundryChatClient); async-first, Python ≥3.11.
↩ tiền nhiệm: Semantic Kernel + AutoGen (hợp nhất)
FoundryChatClient
Client của Agent Framework dùng endpoint Responses của Foundry.
as_tool()
Biến 1 agent con thành tool của agent giám sát (supervisor pattern).
AgentSession / thread persistence
Quản lý phiên hội thoại của Agent Framework; serialize/khôi phục để resume.

Multi-agent

Sequential pipeline
Điều phối tuần tự: output bước này là input bước sau.
Concurrent (fan-out/fan-in)
Chạy song song nhiều nhánh (fan-out) rồi tổng hợp (fan-in).
Handoff
Định tuyến động: router chuyển việc cho agent chuyên gia theo intent.
Supervisor / agent-as-tool
Agent điều phối gọi các agent con như tool, kiểm soát tập trung.
Group chat / Reflection
Vòng phản biện Generator ↔ Critic (self-critique) tới khi đạt tiêu chí.
Magentic / WorkflowBuilder
Các pattern/orchestration dựng sẵn trong Agent Framework.

RAG & Search

RAG (Retrieval-Augmented Generation)
Kiến trúc: truy xuất tài liệu liên quan rồi đưa vào ngữ cảnh để model trả lời có dẫn chứng.
Azure AI Search
Dịch vụ tìm kiếm (keyword + vector + semantic) làm nền RAG.
↩ tiền nhiệm: Azure Cognitive Search
Index
Kho tài liệu đã cấu trúc để truy vấn.
Indexer
Thành phần tự động kéo dữ liệu từ nguồn (blob…) vào index.
Skillset
Chuỗi enrichment AI (OCR, split/chunk, embedding) khi ingest.
Integrated vectorization / Import data (new)
Wizard tự chunk + tạo embedding khi index và khi query.
↩ tiền nhiệm: Import and vectorize data
Vector search / Hybrid search
Tìm theo ngữ nghĩa (vector) / kết hợp keyword (BM25) + vector.
Semantic ranker
Xếp hạng lại (L2) kết quả + trích caption/answer; cần semantic configuration.
Search Explorer
Công cụ thử truy vấn index ngay trên Azure Portal.
Foundry IQ
Lớp tri thức quản lý trên Azure AI Search (knowledge base + agentic retrieval).
Knowledge base / Knowledge source
KB gom nhiều nguồn (blob/SharePoint/index…) sau 1 endpoint có phân quyền.
Agentic retrieval
Hệ thống tự lập kế hoạch truy vấn đa nguồn, áp quyền, trả lời có citation.
Reasoning effort
Mức suy luận của agentic retrieval; đổi cost/latency (minimal = chỉ semantic, không LLM).

Computer Vision

↩ tiền nhiệm: Computer Vision 3.x
Read / OCR (Optical Character Recognition)
Đọc chữ (in & viết tay) trong ảnh.

Image generation

Video generation (Sora)

Vision Studio

Language

Text Analytics
Nhóm tính năng Language: NER, PII, sentiment, summarization.
↩ tiền nhiệm: azure-cognitiveservices-language-textanalytics
NER (Named Entity Recognition)
Nhận diện thực thể (người, địa điểm, tổ chức…).
PII (Personally Identifiable Information) redaction
Phát hiện + che thông tin nhạy cảm (trả redacted_text).
Sentiment / opinion mining
Phân tích cảm xúc theo câu + theo khía cạnh.
Summarization (extractive/abstractive)
Tóm tắt bằng trích câu / viết lại.
CLU (Conversational Language Understanding)
Hiểu intent/entity của hội thoại.
↩ tiền nhiệm: LUIS
Language Studio
Giao diện tạo/huấn luyện CLU & các tính năng Language (đang migrate sang Foundry 20/03/2027).
Translator / Document translation
Dịch text nhanh / dịch tài liệu hàng loạt (async qua blob).

Speech

STT / TTS (Speech-to-Text / Text-to-Speech)
Speech-to-text / Text-to-speech.
SSML (Speech Synthesis Markup Language)
Ngôn ngữ đánh dấu điều khiển ngữ điệu/tốc độ/ngắt nghỉ của TTS.
Neural voice
Giọng đọc chất lượng cao của TTS.
Speech Studio
Giao diện thử STT/TTS/SSML/custom voice (speech.microsoft.com).
Voice Live
Giọng nói thời gian thực (speech-to-speech), hợp nhất STT+LLM+TTS; SDK azure-ai-voicelive (async).

Information Extraction

Document Intelligence
Trích cấu trúc/field từ tài liệu (layout, invoice, ID…).
↩ tiền nhiệm: Form Recognizer
prebuilt-layout / -invoice / -idDocument
Model có sẵn: cấu trúc+bảng / hoá đơn / giấy tờ tuỳ thân.
Confidence
Độ tin cậy của field trích được.
Document Intelligence Studio
Giao diện thử model DI (documentintelligence.ai.azure.com).
↩ tiền nhiệm: Form Recognizer Studio
Content Understanding
Trích xuất đa phương thức (document/image/audio/video) theo schema/markdown.
Analyzer (prebuilt/custom)
Bộ phân tích của CU; custom analyzer định nghĩa schema riêng.
extract / generate / classify
3 kiểu field trong custom analyzer: rút sẵn / model sinh / phân loại.
Content Understanding Studio
Giao diện tạo & test analyzer (chọn 'new Content Understanding experience').

Responsible AI

Content Safety
Kiểm duyệt nội dung theo 4 nhóm hại + mức severity.
↩ tiền nhiệm: Content Moderator
Guardrails & controls
Khu cấu hình content filter/prompt shields trong New Foundry.
Content filter / severity
Lọc theo 4 mức (0 safe / 2 / 4 / 6); mặc định medium; 'safe' chỉ annotate.
Harm categories
4 nhóm: Hate, SelfHarm, Sexual, Violence.
Prompt Shields
Chống prompt injection / jailbreak.
Evaluator (groundedness/relevance/safety)
Bộ chấm điểm chất lượng/an toàn (azure-ai-evaluation), dùng 1 model giám khảo.
Groundedness
Mức câu trả lời bám dữ liệu nguồn (ngược với bịa).

Observability & Ops

OpenTelemetry / tracing / span
Chuẩn ghi vết; span = 1 bước; trace = chuỗi span của 1 run.
Application Insights
Nơi lưu trace/metric; bật tracing bằng cách connect vào project.
Online evaluation / error analysis
Chấm điểm trên traffic thật + phân tích mẫu lỗi/điểm thấp.
Annotations
Phản hồi con người gắn vào run để giám sát chất lượng.
Fine-tuning (SFT/DPO/RFT)
Customize model bằng dữ liệu JSONL (JSON Lines). SFT = Supervised Fine-Tuning; DPO = Direct Preference Optimization; RFT = Reinforcement Fine-Tuning.
CI/CD (Continuous Integration / Continuous Delivery)
Tự động build→test→deploy; đăng nhập keyless bằng OIDC (OpenID Connect) + federated credential, không secret.
uv
Trình quản lý package/môi trường Python (thay pip) dùng trong repo này.
