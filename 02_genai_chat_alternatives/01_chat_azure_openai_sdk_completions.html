Lab 02/01 · Chat Playground

Thử model chat trực quan trong New Foundry Playground (tương ứng cách gọi SDK ở file code).

Foundry PlaygroundChatDeployment

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) (giữ nguyên project đang mở). Hướng dẫn này theo New Foundry — bật toggle đó ON trước khi làm.
Mục tiêu: Chat thử với model đã deploy, chỉnh system message + tham số — trước khi viết code.

Chuẩn bị

  • 1 model chat đã deploy (lab 01/02).

Các bước trên Portal

  1. Mở Chat playground
    New Foundry → Playground → Chat → chọn deployment.
  2. Cấu hình
    Nhập system message (vai trò) + chỉnh temperature / max tokens.
  3. Chat & xem code
    Gõ câu hỏi → xem trả lời; bấm View code để lấy snippet (openai SDK).
Nghiệm thu: Model trả lời; View code ra snippet khớp với file .py.
Lưu ý thi: Playground = thử nhanh; code = openai SDK; model = tên deployment. (File .py dùng AzureOpenAI classic để đối chiếu; khuyến nghị OpenAI /v1.)

Tham khảo (trang có ảnh minh hoạ)

  • Foundry playgrounds (image/video/audio) — có ảnh

Đối chiếu với code

Cùng việc này bằng code ở 01_chat_azure_openai_sdk_completions.py. Portal = làm tay / trực quan; code = tự động hoá, CI-CD.

Tài liệu học — không phải nguồn chính thức. Giao diện Portal đổi thường xuyên; luôn đối chiếu link Microsoft Learn ở trên.
