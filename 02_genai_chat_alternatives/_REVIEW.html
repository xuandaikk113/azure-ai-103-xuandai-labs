Review 02 · GenAI Chat Alternatives

3 cách gọi model: Chat Completions vs Responses API vs Foundry Models /v1; streaming, structured JSON schema, multimodal, prompt engineering. Ôn nhanh + bẫy thi.

1. Tóm tắt

  • 3 "mặt" của cùng OpenAI SDK: chat.completions.create (cổ điển, dùng messages), responses.create (chuẩn mới agentic, dùng input/instructions), và Foundry Models (model non-OpenAI) cùng đi qua endpoint OpenAI /v1.
  • Endpoint v1 khuyến nghị: OpenAI(base_url=".../openai/v1/") — KHÔNG cần api_version. Cách classic AzureOpenAI(azure_endpoint=..., api_version=...) vẫn chạy nhưng cũ hơn.
  • model = tên DEPLOYMENT, không phải tên model gốc.
  • Responses API là nền cho agent và chuỗi previous_response_id (xem chương 03/04); hợp nhất Chat Completions + Assistants API cũ.
  • Streaming: stream=True → lặp các delta. Structured output: response_format kiểu json_schema với strict:true + additionalProperties:false.
  • Multimodal: gửi content parts (input_text/input_image/input_audio) cho model hỗ trợ (vd gpt-4o).
  • Prompt engineering: system message + few-shot + grounding + tham số (temperature/top_p/max_tokens) = cách "optimize" rẻ nhất, không đụng trọng số.

2. Cú pháp cần nhớ

# Client v1 (khuyến nghị) — một client cho cả chat lẫn responses:
from openai import OpenAI
client = OpenAI(base_url=endpoint.rstrip("/") + "/openai/v1/", api_key=key)
#   Keyless: api_key=get_bearer_token_provider(DefaultAzureCredential(),
#                       "https://ai.azure.com/.default")   # scope cho /v1

# (1) Chat Completions — cổ điển, messages[]:
r = client.chat.completions.create(model=deployment,
        messages=[{"role":"system","content":"..."},{"role":"user","content":"..."}])
print(r.choices[0].message.content)

# (2) Responses API — input + instructions, output_text, có id để nối lượt:
resp = client.responses.create(model=deployment,
        instructions="~ system message", input="câu hỏi")
print(resp.output_text, resp.id)

# (3) Streaming:
stream = client.chat.completions.create(model=deployment, messages=[...], stream=True)
for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

# (4) Structured output (JSON Schema strict):
response_format={"type":"json_schema",
    "json_schema":{"name":"ho_so","schema":schema,"strict":True}}
#   schema cần "additionalProperties": False + liệt kê "required".
#   Gọn hơn: client.responses.parse(model=..., input=..., text_format=PydanticModel)

# (5) Foundry Models (non-OpenAI) — CÙNG /v1, chỉ đổi model + embeddings:
client.chat.completions.create(model="", messages=[...])
client.embeddings.create(model=embed_deployment, input="text")   # ra vector

3. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
chat.completions vs responsescompletions = messages[] + choices[0].message.content, stateless. responses = input/instructions + output_text + previous_response_id (state nhẹ server), là nền cho agent/tools. Đề nói "multi-turn/agentic/nối lượt không gửi lại lịch sử" → Responses.
Azure OpenAI endpoint vs Foundry Models endpointCùng OpenAI /v1, cùng SDK. Azure OpenAI = model của OpenAI (gpt-4o…). Foundry Models = catalog non-OpenAI (Llama/Mistral/DeepSeek/Cohere) qua Serverless (MaaS). Khác nhau ở model name và tài nguyên, không khác cách gọi.
azure-ai-inference (ChatCompletionsClient) vs OpenAI SDKazure-ai-inference đã DEPRECATED (retire 2026-08-26). Đề nhắc ChatCompletionsClient/EmbeddingsClient = dấu hiệu đáp án cũ → chọn OpenAI SDK /v1.
Structured output (json_schema strict) vs json_object modejson_object chỉ đảm bảo "là JSON hợp lệ". json_schema + strict:true ép đúng schema (field, kiểu). Đề nói "đảm bảo đúng cấu trúc/kiểu" → json_schema strict.
Prompt engineering vs Fine-tune vs RAGPrompt/tham số: đổi chỉ dẫn, rẻ nhất, không đụng model. Fine-tune: đổi trọng số (JSONL, tốn hosting). RAG: thêm tri thức lúc chạy. Đề "thêm kiến thức mới thường xuyên" → RAG; "đổi tone/format cố định" → prompt trước, fine-tune sau.

4. Exam tips & bẫy

  • Đề nói "multi-turn, agentic, nối hội thoại server-side" → Responses API (previous_response_id), không phải chat.completions.
  • Đề nói "in dần token real-time / UX gõ chữ" → streaming (stream=True, đọc delta).
  • Đề nói "output phải đúng schema để code xử lý" → Structured output json_schema strict (+additionalProperties:false), hoặc responses.parse với Pydantic.
  • Đề nói "gọi Llama/Mistral/DeepSeek" → Foundry Models qua OpenAI /v1, chỉ đổi model.
  • model phải là tên deployment; sai tên → 404 DeploymentNotFound (không phải lỗi quyền).
  • Endpoint /v1 không cần api_version; token scope là https://ai.azure.com/.default (không phải cognitiveservices.azure.com — scope đó cho AzureOpenAI classic).
  • Multimodal: chỉ model hỗ trợ modality (vd gpt-4o) mới nhận ảnh/audio; cẩn thận prompt-injection giấu trong ảnh.
  • Giảm "bịa" (fabrication): grounding + temperature thấp, không nhất thiết fine-tune.
