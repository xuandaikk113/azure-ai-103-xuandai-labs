Lab 00/01 · Tạo Storage Account + Blob Container

Hướng dẫn trực quan trên Azure Portal, song song file code 01_provision_storage_blob.py.

Azure PortalStorage accountBlob container~5 phút

ℹ️ Đây là Azure Portal (portal.azure.com), KHÔNG phải Foundry portal — không có nút toggle "New Foundry". Làm theo điều hướng Azure Portal bên dưới.
Mục tiêu: Tạo 1 storage account + container documents để chứa dữ liệu RAG / dịch document / fine-tune.

Chuẩn bị

  • Có subscription + quyền tạo tài nguyên (Contributor/Owner trên resource group).

Luồng tổng quan

flowchart LR P[portal.azure.com] --> C[Create a resource] C --> S[Storage account] S --> R[Review + create] R --> CT[Containers] CT --> ADD[+ Container 'documents']

Các bước trên Portal

  1. Tạo storage account
    portal.azure.com → Create a resource → tìm Storage account → Create.
  2. Cấu hình cơ bản
    Subscription + Resource group + Storage account name (duy nhất toàn cầu) + Region + Redundancy LRS → Review + create → Create.
  3. Tạo container
    Mở storage account → Data storage → Containers → + Container → tên documents → Public access level: Private → Create.
  4. Cấp quyền keyless (khuyến nghị)
    Tab Access Control (IAM) → Add role assignment → Storage Blob Data Contributor → gán cho user/managed identity.
Nghiệm thu: Container documents xuất hiện trong danh sách Containers.

Ví dụ

BLOB_CONNECTION_STRING=<Access keys → Connection string>
STORAGE_ACCOUNT_NAME=mystorage123
Lưu ý thi: Connection string nằm ở Access keys (là bí mật). Ưu tiên keyless qua role Storage Blob Data Contributor thay vì key.

Tham khảo (trang có ảnh minh hoạ)

  • Tạo blob container trên Azure Portal — có ảnh
  • Assign roles (Access control/IAM) — có ảnh
