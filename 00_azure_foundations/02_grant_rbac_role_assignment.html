Lab 00/02 · Gán quyền RBAC (Access control / IAM)

Hướng dẫn trực quan trên Azure Portal, song song file code 02_grant_rbac_role_assignment.py.

Azure PortalRBACIAM~3 phút

ℹ️ Đây là Azure Portal (portal.azure.com), KHÔNG phải Foundry portal — không có nút toggle "New Foundry". Làm theo điều hướng Azure Portal bên dưới.
Mục tiêu: Gán 1 role cho principal (user / managed identity) ở phạm vi (scope) phù hợp — quyền thừa kế xuống dưới.

Chuẩn bị

  • Cần quyền Owner hoặc User Access Administrator trên scope muốn gán.

Các bước trên Portal

  1. Mở Access control (IAM)
    Mở resource (hoặc Resource group) → menu trái Access control (IAM).
  2. Add role assignment
    + Add → Add role assignment.
  3. Chọn Role
    Tab Role → chọn vai trò (vd Cognitive Services User).
  4. Chọn Members
    Tab Members → User, group, or service principal (hoặc Managed identity) → chọn đối tượng.
  5. Hoàn tất
    Review + assign. Đợi vài phút để quyền có hiệu lực.

Nghiệm thu: Role mới hiện ở tab Role assignments của resource.
Lưu ý thi: RBAC = principal + role + scope (thừa kế xuống). Nguyên tắc least privilege: role hẹp nhất, scope nhỏ nhất.
