1 · Cấu trúc tài nguyên Azure

Mọi thứ nằm trong một cây phân cấp. Nhớ thứ tự này để hiểu scope của RBAC và cách tổ chức dự án.

flowchart TD T["Microsoft Entra ID
(tenant / danh tính)"] --> S["Subscription
(đơn vị tính tiền)"] S --> RG["Resource Group
(nhóm tài nguyên theo vòng đời)"] RG --> F["Foundry resource + project"] RG --> AOAI["Azure OpenAI"] RG --> SEARCH["Azure AI Search"] RG --> ST["Storage account (blob)"] RG --> KV["Key Vault"] F -. connection .-> SEARCH F -. connection .-> ST F -. connection .-> KV
  • Tenant (Entra ID): nơi quản lý danh tính (user, group, app/service principal, managed identity).
  • Subscription: ranh giới tính tiền & quota.
  • Resource Group: gom tài nguyên cùng vòng đời (xoá RG = xoá hết bên trong).
  • Foundry project: trung tâm của app/agent; kết nối (connection) tới Search/Storage/Key Vault.

3 · RBAC — cấp quyền (Web UI & bằng code)

RBAC = ai (principal) được làm gì (role) ở phạm vi nào (scope). Quyền thừa kế xuống dưới: gán ở RG thì áp cho mọi resource trong RG.

flowchart TD MG["Management Group"] --> SUB["Subscription"] SUB --> RG["Resource Group"] RG --> RES["Resource đơn lẻ"] note["Gán role ở cấp nào thì thừa kế xuống mọi cấp dưới"]:::n MG -.-> note classDef n fill:#2a2f3a,stroke:#4aa3ff,color:#e6e8eb;

Cách gán qua Web UI (Azure Portal)

  1. Mở resource (hoặc RG) → menu trái Access control (IAM).
  2. + Add → Add role assignment.
  3. Tab Role: chọn vai trò (vd Cognitive Services User).
  4. Tab Members: chọn User, group, or service principal (hoặc Managed identity) → chọn đối tượng.
  5. Review + assign. Đợi vài phút để quyền có hiệu lực.

Cách gán bằng Azure CLI

az role assignment create \
  --assignee "<objectId của user/MI/SP>" \
  --role "Cognitive Services User" \
  --scope "/subscriptions/<sub>/resourceGroups/<rg>/providers/Microsoft.CognitiveServices/accounts/<account>"

Cách gán bằng code (Python)

→ Lab 00_azure_foundations/02_grant_rbac_role_assignment.py dùng azure-mgmt-authorization (tạo RoleAssignment với role_definition_id + principal_id + scope).

5 · Storage cho AI

Nhiều lab cần blob: ingest tài liệu (RAG), input/output dịch document, dữ liệu train fine-tune.

# Tạo nhanh bằng Azure CLI

az storage container create --account-name <name> -n documents --auth-mode login
