Lab 09/02 · Evaluation + Monitoring

Đánh giá hành vi agent + giám sát sau deploy trong New Foundry.

Foundry EvaluateMonitoringError analysis

⚙️ Nút toggle "New Foundry": ở thanh banner trên cùng của portal có công tắc chuyển giữa New Foundry và Foundry (classic) (giữ nguyên project đang mở). Hướng dẫn này theo New Foundry — bật toggle đó ON trước khi làm.
Mục tiêu: Online evaluation (groundedness/safety) + monitoring + error analysis cho agent đã deploy.

Chuẩn bị

  • Foundry project + agent đã chạy (có trace).

Các bước trên Portal

  1. Mở Evaluate
    New Foundry → Evaluate → chọn evaluator (groundedness / relevance / safety).
  2. Chạy evaluation
    Chọn dataset / traces thật → chạy → xem điểm từng metric.
  3. Monitor
    Dashboard monitoring + annotations (human feedback) để điều tra mẫu điểm thấp.
Nghiệm thu: Có điểm đánh giá + cảnh báo mẫu điểm thấp.
Lưu ý thi: Evaluate agent behavior + error analysis là skill riêng. Safety evaluator chấm theo rubric; điểm cần diễn giải theo rubric, không chỉ so sánh.

Tham khảo (trang có ảnh minh hoạ)

  • Agent tracing & observability
  • Trace agent setup (App Insights) — có ảnh
