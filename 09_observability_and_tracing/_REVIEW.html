Review 09 · Observability & Tracing

OpenTelemetry tracing → Application Insights (token/latency/tool spans); monitoring + online evaluation (groundedness/safety, error analysis). Ôn nhanh + bẫy thi.

Set up observabilityOpenTelemetryMonitoringOnline Evaluation

1. Tóm tắt

  • Tracing = ghi lại từng bước agent dưới dạng span (OpenTelemetry chuẩn mở), xuất lên Application Insights qua configure_azure_monitor(connection_string=...).
  • Trace cho thấy: token usage, latency breakdown, các tool call / model call, lỗi — để debug & tối ưu.
  • Monitoring = theo dõi liên tục agent đã deploy (traffic, lỗi, chi phí) trên dashboard Foundry + App Insights.
  • Online evaluation = chấm hành vi agent trên dữ liệu thật đang chạy bằng evaluators: GroundednessEvaluator (có bịa không), safety, relevance; kèm error analysis.
  • Offline model eval (dataset cố định, trước deploy) KHÁC online agent eval (traffic thật, sau deploy). Đề thi tách riêng 2 skill này.

2. Cú pháp cần nhớ

# TRACING — 1 dòng bật export lên Application Insights:
from azure.monitor.opentelemetry import configure_azure_monitor
configure_azure_monitor(connection_string=cfg["APPLICATIONINSIGHTS_CONNECTION_STRING"])
# -> sau đó agent/azure-ai-projects tự phát span: token, latency, tool call

# ONLINE EVALUATION — chấm response thật bằng evaluator:
from azure.ai.evaluation import RelevanceEvaluator, GroundednessEvaluator
relevance    = RelevanceEvaluator(model_config)
groundedness = GroundednessEvaluator(model_config)

rel = relevance(query=q, response=r, context=ctx)
gnd = groundedness(query=q, response=r, context=ctx)   # context = tài liệu ground
score = gnd.get("groundedness")                        # thấp -> nghi "bịa" (hallucination)

# Biến .env chính: APPLICATIONINSIGHTS_CONNECTION_STRING, FOUNDRY_PROJECT_ENDPOINT

3. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
Offline model eval vs Online agent evalOffline = dataset cố định, chạy trước deploy để chọn model/prompt. Online = chấm traffic thật đang chạy (sau deploy) + error analysis hành vi agent.
Tracing vs Monitoring vs EvaluationTracing = ghi chi tiết 1 lần chạy (span). Monitoring = theo dõi liên tục số liệu tổng hợp (traffic/lỗi/chi phí). Evaluation = chấm chất lượng output (groundedness/safety).
Application Insights vs Azure MonitorAzure Monitor = nền tảng; Application Insights = thành phần APM nhận telemetry. configure_azure_monitor đẩy OpenTelemetry vào App Insights.
GroundednessEvaluator vs Content SafetyGroundedness = output có bám vào context/bịa không (chất lượng RAG). Content Safety = nội dung độc hại (Hate/Violence...). Khác mục đích.
Span vs metricSpan = 1 đơn vị công việc có thời gian + thuộc tính (tool call, model call). Metric = số đo tổng hợp (count/latency trung bình).

4. Exam tips & bẫy

  • Đề nói "xem token/latency/tool call của từng lần agent chạy" → OpenTelemetry tracing + configure_azure_monitor → Application Insights.
  • Đề nói "đánh giá agent có bịa đặt không trên dữ liệu thật" → online evaluation + GroundednessEvaluator.
  • Đề nói "so sánh model/prompt trên bộ test cố định trước khi deploy" → offline evaluation (không phải online).
  • Đề nói "theo dõi liên tục agent production (traffic/lỗi/chi phí)" → monitoring dashboard, không chỉ tracing 1 lần.
  • Groundedness thấp = dấu hiệu hallucination → cần điều tra prompt/RAG, không phải lỗi hạ tầng.
  • Cần biến APPLICATIONINSIGHTS_CONNECTION_STRING để export trace; thiếu → không thấy telemetry.
  • Tracing dùng chuẩn mở OpenTelemetry (không phải logging tự chế) → tương thích công cụ APM khác.
