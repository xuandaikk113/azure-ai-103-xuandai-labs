🧰 Document Intelligence Studio tại documentintelligence.ai.azure.com (không phải Foundry portal) — cần chọn resource (endpoint + key). Đổi tên từ Form Recognizer Studio.
Mục tiêu: Dùng model Layout để trích text, đoạn, bảng, selection marks, toạ độ.

Chuẩn bị

  • 1 Document Intelligence (hoặc Foundry) resource — Studio cần endpoint + key.
  • File mẫu PDF/ảnh.

Các bước trên Portal

  1. Mở Studio
    Vào documentintelligence.ai.azure.com → đăng nhập → chọn resource (endpoint + key).
  2. Chọn Layout
    Trang chủ → mục Layout.
  3. Upload + phân tích
    Dùng file mẫu hoặc Upload → Run analysis (chỉnh Analyze options nếu cần).
  4. Xem kết quả
    Xem text/bảng/selection marks được highlight + JSON output ở panel bên.
Nghiệm thu: Kết quả hiển thị bảng + cấu trúc; copy được JSON.
Lưu ý thi: Layout cho cấu trúc + bảng. Đổi tên từ Form Recognizer. Hỗ trợ PDF/ảnh/Office.

Tham khảo (trang có ảnh minh hoạ)

  • Dùng Document Intelligence Studio — có ảnh
