Lab 08/03 · Content Understanding Studio · Prebuilt document

Phân tích tài liệu bằng prebuilt analyzer trên Content Understanding Studio.

Content Understanding Studioprebuilt analyzerDocument

🧰 Content Understanding Studio — nhớ chọn "try the new Content Understanding experience" để có đa phương thức. Foundry portal chỉ có vài prebuilt; custom analyzer làm ở Studio. Model mặc định: gpt-4.1 retire 10/2026 → chuyển gpt-5.2.
Mục tiêu: Dùng prebuilt analyzer để trích nội dung tài liệu ra schema/markdown sạch cho RAG/agent.

Chuẩn bị

  • Foundry/CU resource + default model (vd gpt-5.2).
  • File tài liệu.

Các bước trên Portal

  1. Mở Studio
    Content Understanding Studio → chọn 'try the new Content Understanding experience'.
  2. Tạo project
    Create project → đặt tên → upload sample data.
  3. Chọn prebuilt analyzer
    Chọn analyzer tài liệu có sẵn (document) → phân tích file.
  4. Xem kết quả
    Xem fields + markdown output; lấy được code/API.
Nghiệm thu: Kết quả trích đúng field/markdown của tài liệu.
Lưu ý thi: CU thống nhất doc/audio/video/image. Foundry portal chỉ có vài prebuilt; custom → CU Studio.

Tham khảo (trang có ảnh minh hoạ)

  • Content Understanding Studio quickstart — có ảnh

Đối chiếu với code

Cùng việc này bằng code ở 03_content_understanding_prebuilt_document_analyzer.py. Portal = làm tay / trực quan; code = tự động hoá, CI-CD.
