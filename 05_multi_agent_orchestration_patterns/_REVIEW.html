Review 05 · Multi-Agent Orchestration Patterns

Microsoft Agent Framework: sequential pipeline, concurrent fan-out/fan-in, handoff routing, supervisor agent-as-tool, group chat / reflection loop. Ôn nhanh + bẫy thi.

Agent FrameworkSequentialConcurrentHandoffSupervisorReflection

1. Tóm tắt

  • Nền chung: Microsoft Agent Framework (code-first, async, Python ≥ 3.10/3.11). Hợp nhất AutoGen (orchestration) + Semantic Kernel (workflow). Mỗi pattern = tạo vài Agent(client=FoundryChatClient(...)) rồi ghép.
  • Sequential: output bước này là input bước sau (Researcher → Writer → Reviewer). Tuyến tính, dễ suy luận.
  • Concurrent (fan-out/fan-in): chạy N agent SONG SONG (asyncio.gather) rồi 1 aggregator tổng hợp. Giảm latency, cần bước fan-in.
  • Handoff: router/triage đọc intent rồi trao quyền cho agent chuyên gia phù hợp — định tuyến động.
  • Supervisor (agent-as-tool): supervisor coi agent con như tool (.as_tool()), tự quyết gọi cái nào, kiểm soát tập trung.
  • Group chat / Reflection: vòng lặp Generator ↔ Critic, lặp tới khi "ĐẠT" hoặc hết vòng — nâng chất lượng, bắt buộc có điều kiện dừng.
  • Dựng sẵn: cài agent-framework-orchestrations để dùng SequentialBuilder / ConcurrentBuilder / HandoffBuilder / MagenticBuilder / GroupChatBuilder (.build() → Workflow, await wf.run(task) → .get_outputs()); WorkflowBuilder cho graph Executor + edges tuỳ biến. Các lab 05 giờ dùng builder thật, bản ghép tay giữ trong comment để đối chiếu.

2. Cú pháp cần nhớ

# Mẫu tạo agent (dùng cho mọi pattern):
from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
def make_agent(name, instructions):
    return Agent(client=FoundryChatClient(project_endpoint=ep, model=MODEL,
                 credential=DefaultAzureCredential()), name=name, instructions=instructions)

# (1) Sequential — nối tay: output trước -> input sau
research = await researcher.run(f"Nêu ý về: {topic}")
draft    = await writer.run(f"Viết đoạn từ:\n{research.text}")
review   = await reviewer.run(f"Góp ý:\n{draft.text}")

# (2) Concurrent — fan-out song song rồi fan-in tổng hợp
results = await asyncio.gather(*(a.run(prompt) for a in agents.values()))
summary = await aggregator.run("Tổng hợp:\n" + "\n".join(r.text for r in results))

# (3) Handoff — router phân loại intent rồi trao quyền
label = (await router.run(request)).text.strip().lower()
reply = await specialists[label].run(request)

# (4) Supervisor as tool — agent con thành tool của supervisor
#   agent-framework: child.as_tool()  -> supervisor tự quyết gọi tool nào
translation = (await translate_agent.run(text)).text
result = await supervisor.run(f"Tổng hợp:\n- Dịch: {translation} ...")

# (5) Reflection loop — Generator <-> Critic, có điều kiện dừng
for _ in range(1, 4):                      # giới hạn vòng -> tránh lặp vô hạn
    feedback = (await critic.run(f"Chấm: {draft}")).text
    if "ĐẠT" in feedback.upper(): break
    draft = (await generator.run(f"Sửa theo: {feedback}")).text

# (phức tạp) WorkflowBuilder: Executor + @handler + ctx.send_message() -> graph có fan-out/loop

3. Dễ nhầm với service khác

Cặp dễ nhầmPhân biệt
Handoff vs Supervisor (agent-as-tool)Handoff = trao TOÀN BỘ quyền cho agent kế tiếp, agent đích trực tiếp trả lời user (điều khiển phi tập trung). Supervisor = agent con chỉ là tool, supervisor giữ quyền và tổng hợp (điều khiển tập trung). Đề "một agent điều phối và gộp kết quả" → supervisor; "chuyển hẳn cho chuyên gia theo intent" → handoff.
Sequential vs ConcurrentSequential = output trước là input sau, có phụ thuộc, chậm hơn. Concurrent = các nhánh độc lập, chạy asyncio.gather, nhanh hơn, cần aggregator fan-in. Đề "giảm latency, nhiều góc nhìn độc lập" → concurrent; "quy trình có thứ tự" → sequential.
WorkflowBuilder vs ChatAgent/AgentAgent = một agent gọi .run(). WorkflowBuilder = graph các Executor nối bằng edge (@handler, ctx.send_message()) cho luồng có fan-out/loop/điều kiện. Đề "điều phối phức tạp, nhiều nhánh/vòng, graph" → WorkflowBuilder.
Reflection vs single callReflection = vòng lặp Generator/Critic để tự cải thiện, tốn token hơn nhưng chất lượng cao. Đề "chất lượng cao, tự rà soát" → reflection; nhớ phải có điều kiện dừng (tiêu chí hoặc max vòng).
Agent Framework orchestration vs Foundry Connected AgentsAgent Framework = điều phối code-first (trong code bạn). Foundry cũng có cơ chế agent gọi agent (A2A/connected) ở phía service (chương 03). Đề "điều phối bằng code, portable" → Agent Framework.

4. Exam tips & bẫy

  • Đề nói "quy trình nhiều bước có thứ tự, bước sau cần kết quả bước trước" → Sequential.
  • Đề nói "nhiều phân tích độc lập, giảm thời gian" → Concurrent fan-out/fan-in (asyncio.gather + aggregator).
  • Đề nói "định tuyến theo intent/loại yêu cầu" → Handoff (router → specialist).
  • Đề nói "một điều phối viên kiểm soát, gọi trợ lý con như công cụ" → Supervisor agent-as-tool (.as_tool()).
  • Đề nói "tự phản biện, cải thiện tới khi đạt" → Reflection/Group chat; luôn có điều kiện dừng kẻo lặp vô hạn.
  • Đề nói "graph nhiều nhánh/vòng, điều kiện phức tạp" → WorkflowBuilder (Executor + edges), không phải chuỗi await phẳng.
  • Agent Framework là async — nhớ await/asyncio.run; mỗi agent nên có client riêng khi chạy song song.
  • Semantic Kernel + AutoGen đã hợp nhất → đề nhắc riêng SK/AutoGen là ngữ cảnh cũ.
